MovieWeb is a modern web-based movie streaming platform designed to provide users with a convenient and engaging entertainment experience. Developed using React.js, Node.js, Express.js, and MongoDB, the application allows users to explore movies, watch trailers, search for titles, manage favorite movies, and interact through ratings and comments. The system also includes user authentication, personalized movie recommendations, and an administrative dashboard for managing movie content, categories, and user accounts. This project demonstrates my skills in full-stack web development, database management, API integration, and responsive user interface design.
